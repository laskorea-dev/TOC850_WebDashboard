# 에이전트 지침서 (Agent Instructions)

이 프로젝트(TOC850_WebDashboard)에서 작업할 때 에이전트가 준수해야 하는 지침입니다.

## 1. 프로젝트 개요 및 목적
- **프로젝트 명**: TOC850_WebDashboard
- **목적**: TOC(총유기탄소) 측정 계측기 데이터를 Supabase 데이터베이스에 업로드하고, 이를 웹 대시보드로 시각화하여 모니터링 및 경보(텔레그램)를 처리하는 시스템입니다.
- **주요 구성**:
  - `gui_uploader.py`: 계측기 PC에서 실행되며 측정 데이터를 Supabase에 업로드하는 Python GUI 프로그램. 원격 정지·주기 조정·공지를 `device_config` 로 받습니다. **경보는 보내지 않습니다**(서버 DB 트리거 → Vercel `/api/send-alert`).
  - `dashboard/`: Supabase 데이터를 실시간으로 모니터링하고 알람 임계치를 설정하는 React/Vite 기반 웹 대시보드 (`dashboard/api/` 에 Vercel 서버리스 함수)

## 2. 작업 수행 시 필수 준수 사항
- **회의록 및 개발 이력 관리**:
  - 사용자 요구사항의 변경이나 작업 완료 시, 반드시 [meeting_notes](file:///d:/antigravity/db_upload_and_dashboard/meeting_notes) 폴더 내에 일자별 회의록(예: `2026-06-18_alert_and_test_page_design.md`)을 작성해야 합니다.
  - 프로젝트의 진척 및 작업 현황은 루트의 [2_투두리스트_Task_List.md](file:///d:/antigravity/db_upload_and_dashboard/2_투두리스트_Task_List.md)에, 누적 개발 타임라인 및 기술 내역은 [3_히스토리_및_완료보고서.md](file:///d:/antigravity/db_upload_and_dashboard/3_히스토리_및_완료보고서.md)에 기록하고 최신화해야 합니다.
- **데이터베이스 스키마 변경 제한**:
  - Supabase 데이터베이스의 기존 테이블 구조는 변경하지 않습니다. 임계치 설정 등 추가 데이터는 기존 `toc_alert_high` 컬럼의 JSON 구조 내에 기록하여 확장합니다.
  - 예외는 `tools/migrations/` 의 번호 붙은 SQL 로만 적용하고, 적용 여부를 그 파일 머리말과 인계 문서에 기록합니다. (2026-09-28 `001` 적용 · `002` 는 키 재발급 후)
- **Git 푸시 제한**:
  - 로컬 테스트 및 사용자의 최종 확인이 완료되기 전까지는 원격 저장소에 `git push`를 하지 않고 로컬 커밋만 유지합니다.
- **답변 언어**:
  - 사용자와의 소통 및 최종 설명은 항상 명확하고 친절한 한국어(한글)로 작성해야 합니다.

## 4. 최종 배포 및 산출물 백업 규칙 (NAS 동기화 — 2026-09-10 자동화됨)

이 PC는 개인용입니다. 담당자 부재·인수인계에 대비해 **NAS 폴더만 가져가면 작업을 이어갈 수 있는 상태**를 유지하는 것이 목표입니다.

```bash
python tools/nas_sync.py              # 전체 동기화
python tools/nas_sync.py --dry-run    # 무엇을 할지만 확인
```

- `build_release.py` 가 빌드 완료 후 **자동 실행**합니다. 업로더를 빌드했다면 따로 할 일이 없습니다.
- **대시보드만 수정했거나 문서만 고쳤다면 직접 실행**하십시오. Vercel 배포는 NAS를 갱신하지 않습니다.
- Z: 미연결 시 경고만 남기고 건너뜁니다(빌드는 계속 성공).
- 동기화 대상: `Z:\05. 개발부\01. 개발프로젝트\01. TOC850\08. 소프트웨어\05. TOC850_웹대시보드\`

| 항목 | 갱신 방식 |
|---|---|
| `01_Uploader_배포패키지` `02_Uploader_원본코드` `03_대시보드_소스코드` `06_저장소_백업.bundle` `07_개발_컨텍스트` | **자동** — 매 실행 시 전체 교체 |

| `04_운영관리_인프라정보.md` `05_아키텍처_구조_명세서.md` | **수기** — 스크립트가 건드리지 않습니다. 내용이 바뀌면 직접 갱신하십시오 |
