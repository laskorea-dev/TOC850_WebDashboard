# 점촌 실험실 대조 — FACT / OFST 산출 (2026-09-02)

점촌하수처리장 원수(CH1, `TOC-260706-01`) 계측값을 실험실 TOC 와 맞추기 위한 보정계수.
대조 구간 **2026-08-13 ~ 09-01**, 실험실 채수 18건 중 분석값이 있는 **14쌍**.
계측기 자료는 Supabase `measure_logs_v2` 원본을 직접 조회했다. 대시보드 집계는 쓰지 않았다.

## 결론

```
FACT = 0.55
OFST = 0.0
```

현재 계측기는 `FACT=1.0 / OFST=0.0`(무보정)이고 실험실 대비 약 1.8배 높게 읽는다.

## 희석배수는 이미 반영돼 있다

`data.json` 755건을 전부 검산해 계측기 내부 공식을 확정했다(**불일치 0건**, `verify_formula.py`).

```
TOC_Conc = (MSIG - ICPT) / SLOP * DilutionFactor * FACT + OFST
```

**DF 가 먼저 곱해지고 FACT 가 그 뒤에 붙는다.** 저장된 `TOC_Conc` 는 이미 희석 보정된
값이므로 FACT 는 희석배수와 무관하게 그대로 얹으면 되고, 나중에 DF 를 ×1 이나 ×10 으로
바꿔도 이 값은 유효하다.

희석기가 정상이라는 근거는 설정 이력에 있다(`dfhist.py`).

| 시각 | DF | SLOP | ICPT | 직전 TOC / MSIG | 직후 TOC / MSIG |
|---|---|---|---|---|---|
| 2025-06-30 10:21 | ×1 | 144.16 | 54.13 | — | 0.82 / 173 |
| 2026-07-15 16:06 | ×1 | 127.87 | 83.42 | 9.69 / 1,452 | 0.00 / 84 |
| 2026-07-30 13:53 | ×5 | 127.87 | 83.42 | **95.91 / 12,347** | **99.23 / 2,621** |

×1 → ×5 전환에서 표시값에 단차가 없다(95.91 → 99.23). MSIG 는 12,347 → 2,621 로 4.7배
떨어졌다. 실제 물리 희석과 DF 설정이 같이 움직였다는 뜻이다.
(덧붙여, ×1 시절 MSIG 12,347 은 검출기 선형범위를 넘겼을 가능성이 크다. ×5 로 올린 것은 타당하다.)

교정상수 `SLOP=127.87 / ICPT=83.42` 는 2026-07-15 이후 그대로다.

## 오차는 곱셈형이다 — OFST 를 0 으로 두는 이유

희석수에 TOC 가 섞이는 오염이라면 오차는 덧셈형이어야 한다(기울기 1, 절편만 음수).
같은 자료에 두 모델을 태우면 갈린다(`model.py`).

| 모델 | 식 | RMSE (실험실<10 제외) |
|---|---|---|
| 곱셈형 | y = 0.534·x | **4.56** |
| 덧셈형 | y = x − 24.17 | 11.26 |

- (계측기 − 실험실) vs 계측기값 상관 **r = +0.92** → 차이가 농도에 비례
- (실험실 / 계측기) vs 계측기값 상관 **r = −0.10** → 비율은 농도와 무관

덧셈형이면 부호가 반대로 나와야 한다. 희석수 오염이 아니라 교정 기울기(span) 문제다.

절편을 자유롭게 두고 회귀하면 부분집합마다 **−7.5 ~ +6.1** 로 요동치고 유의하지도 않다.
그 요동 자체가 OFST 를 0 으로 고정하라는 근거다.

## FACT 0.55 의 근거

`fit.py` 가 추정법 3종 × 부분집합 5종을 돌린다.

| 추정 | FACT |
|---|---|
| 비율 중앙값 (n=14) | 0.548 |
| 원점통과 회귀, 실험실<10 제외 (n=12) | 0.534 |
| OLS 절편자유, 실험실<10 제외 | 0.561 (절편 −1.68, 유의하지 않음) |
| 이상치 4점 제외 (n=10) | 0.570 (R² 0.978) |

비율 95% 신뢰구간 **0.48 ~ 0.59**. 0.55 적용 시 신뢰 12점 기준 평균오차 +1.1, RMSE 4.7.

## 남는 문제

1. **실험실 이상치 2건.** 8/18(9.6)과 8/25(7.2)는 원수 TOC 로 비현실적이고, 그날 계측기는
   42~45 로 평온했다. 이 둘을 넣으면 FACT 가 0.50 까지 끌려 내려간다. 채수·분석 기록 확인 필요.

2. **잔차가 한쪽으로만 튄다.** 큰 잔차는 전부 "계측기가 높은" 방향(+3.2 ~ +17.6)이고
   반대쪽은 최대 −2.7 뿐이다. 채수 후 방치·침전이나 실험실 전처리에서 TOC 가 빠지는 쪽이
   의심된다. 상단 군집(비율 0.58~0.64)을 믿는다면 실제 FACT 는 **0.58** 에 가까울 수 있다.
   0.55 는 그 중간의 보수적 값이다.

3. **기울기를 잡아주는 고농도 점이 8/13 하나뿐이다.** 그 점을 빼면 계측기값이
   19.6~55.7 좁은 구간에 몰려 회귀가 무너진다(FACT 0.33, R² 0.17 — `fit.py` 케이스 E).
   **80 PPM 이상 구간에서 대응 채수를 2~3건 더** 확보하면 확정할 수 있다.

4. **8/29 단차.** 일중앙값이 8/28 까지 60~106 이던 것이 8/29 이후 24~36 으로 떨어졌다.
   9/1 비율 0.637 이 기존 범위 안이라 유입수 자체의 변화로 보이지만, 그 무렵 계측기
   점검·세정이 있었는지 확인해둘 것. 있었다면 이 FACT 는 그 이전 구간 기준이 된다.

## 폴더 구성

```
scripts/
  common.py         실험실 대조값(LAB) · Supabase 접속정보 · 공용 로더
  fetch.py          점촌 원자료 전 컬럼 수집 → data.json
  verify_formula.py 계측기 내부 공식 검산 · 일자별 요약
  dfhist.py         희석배수 · 교정상수 변경 이력 (전 기간 조회)
  pair.py           채취시각 ↔ 계측기 최근접값 매칭 → pairs.json
  fit.py            FACT/OFST 추정 (OLS · Theil-Sen · 원점통과 × 부분집합 5종)
  model.py          곱셈형 vs 덧셈형 검정 · 권장안 적용 잔차
  data.json         계측기 원자료 스냅샷 (08-10 ~ 09-02, 755건)
  pairs.json        매칭 결과 14쌍
```

## 다시 돌리려면

```bash
cd scripts
python fetch.py && python verify_formula.py && python pair.py && python fit.py && python model.py
```

실험실 값이 추가되면 `common.py` 의 `LAB` 에 붙이고 위를 다시 돌린다.
