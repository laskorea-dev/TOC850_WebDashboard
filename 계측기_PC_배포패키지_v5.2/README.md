# 💧 TOC B2B GUI Uploader v5.2 (Supabase V3) 배포 및 사용 안내서

본 프로그램은 계측기 PC의 데이터를 Supabase 클라우드 데이터베이스에 실시간 동기화하고, 알람 기준치를 초과할 시 경고 알림(텔레그램 등)을 지원하는 Python GUI 프로그램의 v5.2 배포 패키지입니다.

---

## 1. 주요 변경 사항 및 동작 원리

v5.2 (V3 아키텍처)의 핵심 해결책 및 변경 사항:
1. **기기 고유 ID (Device ID) 수동 편집 제한 (읽기 전용)**:
   * `Device_ID`는 물리적인 PC의 Windows 호스트명(예: `TOC-PC-01`, `TOC-PC-02`)을 자동으로 획득하며, 사용자의 입력 실수를 방지하기 위해 프로그램 UI에서 직접 수정할 수 없도록 **읽기 전용(Readonly)**으로 변경되었습니다. (복사하기는 지원)
2. **주의(Caution) 및 경고(Warning) 2단계 임계치 관리**:
   * 각 채널별로 주의(Caution) 및 경고(Warning) 임계값을 설정할 수 있으며, 이 두 단계를 바탕으로 웹 대시보드 텍스트 및 상태 램프 색상이 분기됩니다.
   * `alert_level` (주의 이상 혹은 경고 이상) 설정 값에 맞추어 알림 발송 조건이 결정됩니다.
3. **독립 다중 기기 격리 관리**:
   * 각 계측기 PC는 자신의 `Device_ID`를 Primary Key로 사용하여 Supabase `device_config` 테이블에 자신만의 설정을 완전히 독립적으로 업로드 및 동기화합니다. 다른 PC의 설정을 덮어쓰지 않습니다.

---

## 2. Supabase 데이터베이스 준비 (최초 1회 필수)

대시보드와 업로더 v5.2가 정상 가동하려면, Supabase 콘솔의 **SQL Editor**에 접속하셔서 아래 SQL DDL 스크립트를 붙여넣고 실행(Run)하셔야 합니다. (기존 v5.1 설치 고객은 생략 가능)

```sql
-- 1. 신규 지점 및 장비 설정 테이블 생성 (device_id가 고유 키)
CREATE TABLE public.device_config (
    device_id text NOT NULL PRIMARY KEY,
    site_id text NOT NULL,
    site_name text NOT NULL,
    passcode text NOT NULL DEFAULT '850',
    alert_emails text NULL,
    telegram_chat_ids text NULL,
    toc_alert_high jsonb NULL,
    use_single_table boolean NOT NULL DEFAULT true,
    created_at timestamp with time zone NOT NULL DEFAULT now()
);

-- 2. 신규 통합 계측 로그 테이블 생성
CREATE TABLE public.measure_logs_v2 (
    id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    "Date_Time" timestamp without time zone NOT NULL,
    "Site_ID" text NOT NULL,
    "Device_ID" text NOT NULL,
    "Channel" smallint NOT NULL,
    "Channel_Name" text NOT NULL,
    "TOC_Conc" numeric(10, 4) NOT NULL,
    "DilutionFactor" numeric(6, 2) NOT NULL DEFAULT 1.0,
    "MSIG" numeric(10, 4) NULL,
    "SLOP" numeric(10, 4) NULL,
    "ICPT" numeric(10, 4) NULL,
    "FACT" numeric(10, 4) NULL,
    "OFST" numeric(10, 4) NULL,
    "Add_note" text NULL,
    created_at timestamp with time zone NOT NULL DEFAULT now()
);

-- 인덱스 설정 (조회 속도 최적화)
CREATE INDEX idx_measure_logs_v2_device_id ON public.measure_logs_v2("Device_ID");
CREATE INDEX idx_measure_logs_v2_date_time ON public.measure_logs_v2("Date_Time");
```

## 3. 계측기 PC 프로그램 설정 방법 (`uploader_config.json`)

업로더 폴더 내의 `uploader_config.json` 파일을 열어 다음 두 값을 환경에 맞춰 편집합니다.

```json
{
    "supabase_table": "measure_logs_v2",
    "site_id": "Samyang_Incheon",
    "device_id": "auto",
    "supabase_url": "YOUR_SUPABASE_URL",
    "supabase_key": "YOUR_SUPABASE_ANON_KEY",
    "alert_type": "telegram",
    "sync_interval_minutes": 5,
    "start_auto_sync": true
}
```

* **`supabase_table`**: 반드시 `"measure_logs_v2"`로 고정해 줍니다.
* **`site_id`**: 최종 설치되는 지점 식별 코드(예: `"Samyang_Incheon"`)를 입력합니다.
* **`device_id`**: 항상 `"auto"`로 둡니다. 프로그램 실행 시 컴퓨터의 실제 Windows 이름을 자동으로 감지하여 데이터베이스의 `Device_ID` 컬럼에 남깁니다.

---

## 4. 프로그램 실행 방법

폴더 내에 위치한 **`1_업로더_실행하기.bat`**를 더블클릭합니다.
* 배치파일이 자동으로 v5.2 버전을 감지하여 백그라운드에서 `gui_uploader_v5.2.exe`를 즉시 실행합니다.
