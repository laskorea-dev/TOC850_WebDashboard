# 회의록: 웹 대시보드 차트 기본축/보조축 스케일 범위를 지정 및 동적 확장 개선

- **일시**: 2026년 7월 21일
- **참석자**: 웹 대시보드 개발팀 (Antigravity Agent & User)
- **주제**: 트렌드 시계열 차트의 Y축(기본축 Left / 보조축 Right) 스케일 범위를 설정된 경고치(Warning Threshold)를 기준으로 기본 지정하고, 데이터를 이탈하는 경우 동적 확장하는 기능 추가

---

## 1. 요구사항 및 변경 배경
- 기존 차트 Y축은 전체 표시 채널의 측정 데이터 최소/최대값에 여유분(padding)을 더해 `[absMin, absMax]` 로 오토스케일링하거나 보조축은 `['auto', 'auto']`로 설정되어 있었음.
- 이로 인해 측정 데이터가 낮거나 변동 폭이 적은 구간에서는 차트 상한선 및 축 눈금이 시각적으로 왜곡되거나 축 간 비대칭이 발생함.
- 사용자 요청에 따라 기본축(Left) 및 보조축(Right) 스케일을 아래 3가지 규칙에 맞추어 재설정함.

---

## 2. 세부 적용 기준 및 구현 내용
1. **기본 스케일 범위 지정**:
   - **하한 (Min)**: 기본 `0`
   - **상한 (Max)**: 해당 축(`left` 또는 `right`)에 배정된 채널들의 **경고치(Warning Threshold) 중 최대값**
     - 예: 기본축에 속한 채널의 경고치가 2000, 1000인 경우 기본 상한은 `2000`
     - 예: 보조축에 속한 채널의 경고치가 50인 경우 기본 상한은 `50`

2. **동적 확장 (Dynamic Extension)**:
   - 플롯 범위(현재 화면 데이터 `chartData`) 내 측정 데이터 중 **기본 경고치 상한을 초과하는 데이터 (`dataMax > maxWarning`)가 있을 경우**:
     - 축의 상한을 데이터 최대값(+ 약 5% 여유 공간 `Math.ceil(dataMax * 1.05)`)으로 동적 확장.
   - 플롯 데이터 중 **0 미만의 음수 데이터 (`dataMin < 0`)가 존재할 경우**:
     - 축의 하한을 데이터 최소값(`Math.floor(dataMin)`)으로 동적 확장.

3. **수동 줌(Y 줌 슬라이더) 지원**:
   - Y축 줌 슬라이더로 조절한 수동 범위(`yMin`, `yMax`)가 존재하는 경우, 슬라이더 수동 입력값을 최우선 적용.
