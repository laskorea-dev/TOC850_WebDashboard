# 📝 개발 회의록 (2026-07-07) - 텔레그램 튜닝 및 설정창 고도화

본 문서는 테스트 대시보드 및 업로더의 텔레그램 즉시 발송 튜닝, 대시보드 패스코드 변경, 알림 수신인 제어 권한 완화 논의 및 구현 이력을 기록한 개발 회의록입니다.

---

## 1. 개요 및 요구사항
- **일시**: 2026-07-07
- **참석자**: USER, Antigravity (AI Coding Assistant)
- **주요 목표**:
  1. 테스트 대시보드(`dashboard-ochre-two-35`) 상의 텔레그램 테스트 및 안내 발송 시, 로컬 uploader 폴링을 기다리지 않고 Vercel(브라우저)에서 즉시 발송되도록 직접 호출 방식으로 개선.
  2. 설정창(설정 모달) 내에서 패스코드를 입력하고 들어온 경우, 어드민 권한 여부와 상관없이 등록된 알림 수신자를 쉽게 삭제할 수 있도록 완화.
  3. 설정 모달 및 어드민 설정 카드 내에 대시보드 접속 패스코드(접속 비밀번호)를 사용자가 직접 변경할 수 있는 입력 창 신설 및 저장 연동.
  4. 사용자 정의 텔레그램 봇 토큰 입력 창 신설 및 `toc_alert_high` JSON 필드 연동 저장, 그리고 로컬 파이썬 uploader의 봇 토큰 자동 감지/동기화 패치.

## 2. 세부 구현 내역

### A. Web Dashboard (`App.jsx` 수정)
1. **Vercel 직접 텔레그램 발송 헬퍼 함수 (`sendTelegramAlert`)**:
   - 사용자가 입력한 `telegram_bot_token` 혹은 기본 토큰(`<TELEGRAM_BOT_TOKEN>`)을 사용하여, 지정된 Chat ID 리스트로 HTML 마크업이 포함된 텔레그램 경보 메시지를 브라우저 단에서 직접 `fetch` 호출하여 발송하도록 구현했습니다.
2. **테스트 텔레그램 발송**:
   - "즉시 테스트 텔레그램 발송" 버튼 클릭 시, 10초 대기 딜레이를 유발하던 Supabase PATCH 플래그 세팅 대신 브라우저가 직접 즉각 전송하고, 성공 여부를 사용자 화면에 0초 만에 띄워줍니다.
3. **수신처 등록 및 삭제 시 환영/작별 메시지**:
   - 신규 텔레그램 수신자가 등록 완료되면 "알림 수신 등록 완료" 환영 메시지를, 수신자가 목록에서 제거되면 "알림 수신 해제 완료" 안내를 해당 Chat ID로 봇이 즉시 자동 전송하도록 구성했습니다.
4. **수신자 삭제 제한 해제**:
   - 설정 모달창(`isConfigModalOpen`) 내부의 알림 수신자 목록에서 `isAdminParam` 검사 조건을 완전히 배제하여, 패스코드 보안을 통과한 유저라면 누구나 자유롭게 `🗑️ 삭제` 버튼을 보고 수신처를 삭제할 수 있도록 개선했습니다.
5. **접속 비밀번호(Passcode) 변경 폼**:
   - "🔑 대시보드 접속 패스코드 변경" 인풋 창을 신설하여, 입력 후 "설정 저장"을 클릭하면 Supabase `device_config` (및 `site_config_v2`)의 `passcode` 컬럼으로 PATCH 되어 실시간 저장/반영됩니다.
6. **커스텀 텔레그램 봇 토큰 폼**:
   - 자체 봇을 사용하고자 하는 고객들을 위해 "🤖 텔레그램 봇 토큰" 입력 창을 신설하고, `toc_alert_high` JSON 내부 필드(`telegram_bot_token`)로 패키징 동기화했습니다.

### B. Python Uploader (`gui_uploader.py` 수정)
1. **봇 토큰 원격 동기화**:
   - 로컬 uploader가 15분 주기로 데이터 업로드를 하거나 10초 주기로 테스트 메일 트리거를 확인할 때, Supabase `device_config` 설정 내 `toc_alert_high` JSON에 포함된 `telegram_bot_token` 값을 감지하여 Uploader의 `self.telegram_bot_token`에 실시간으로 자동 덮어쓰도록 수정했습니다.
   - 이를 통해 관리자가 대시보드 상에서 봇 토큰을 임의 변경하면, 로컬 현장 uploader가 이를 원격 동기화하여 변경된 봇으로 알림을 알아서 발송합니다.

## 3. 검증 상태 (Verification Results)
1. **즉시 발송 정합성**:
   - 텔레그램 Bot API 통신 시 CORS 제한 없이 브라우저에서 `sendMessage`가 정상 동작함을 검증했습니다.
   - Chat ID로 환영/작별 및 테스트 메시지가 0초 딜레이로 모바일에 즉시 전송되었습니다.
2. **패스코드 수정 및 저장**:
   - 대시보드 설정 창에서 신규 비밀번호 입력 후 저장 시, Supabase DB 상에 정상 반영되며, 재로그인창에서 새로운 패스코드로만 정상 인가됨을 검증했습니다.
3. **수신자 목록 제어**:
   - 어드민 주소 파라미터가 없어도 설정 모달 내부에서 `🗑️ 삭제` 버튼이 잘 보이고, 클릭 시 실시간으로 DB `receivers` 배열 및 flat flat columns에서 동시 반영 삭제됨을 확인했습니다.
   - Uploader의 백그라운드 fetch 루틴 로그를 통해 DB에서 변경된 텔레그램 봇 토큰 값을 정상 감지하고 로컬 변수를 덮어씀을 최종 확인했습니다.
