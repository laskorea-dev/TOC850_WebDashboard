# 회의록: 업로더 프로그램 UI 현대화 및 지점 한글명 설정 입력폼 구현

* **일시**: 2026-07-07
* **참석자**: USER, Antigravity (AI 코딩 어시스턴트)
* **주제**: 현장 PC용 업로더 GUI의 UI/UX 대폭 개선 및 웹 대시보드 상에서 지점 한글명을 관리자가 쉽게 변경할 수 있는 설정 폼 구현

---

## 1. 결정 사항

### A. 파이썬 GUI 업로더 UI/UX 프리미엄화 (v5.1)
* **배경**: 기존 Tkinter GUI UI가 투박하고 여러 개의 개별 저장 버튼이 산재하여 현장에서 조작 시 시각적 일관성과 사용성이 크게 저하되었습니다.
* **해결책**:
  * **프레임워크 테마 현대화**: Segoe UI(영문) 및 맑은 고딕(한글) 폰트를 도입하고, B2B 웹 대시보드와 패밀리룩을 이루는 **프리미엄 다크 네이비/시안 테마**(`#0B0F19`)를 구축했습니다.
  * **원형 상태 LED 인디케이터**: 기존 텍스트 형태의 활성 배지를 제거하고, 캔버스를 이용해 부드러운 발광 형태의 원형 LED 상태 표시등(가동 시 초록색, 일시정지 시 주황색)을 적용하여 기기 작동 유무를 시각화했습니다.
  * **인터랙티브 호버 애니메이션**: 마우스 커서 진입/탈출에 따라 버튼 색상이 바뀌는 호버링 이벤트(`bind_hover`)를 연동하여 동적인 반응성을 향상시켰습니다.
  * **폴더블(접이식) 레이아웃**: 평소에는 SQLite DB 파일 경로 및 지점 식별자(Site ID)만 노출되도록 콤팩트하게 창 크기(`640x545`)를 조절하고, 인프라 담당자를 위한 복잡한 Supabase 연결 URL/Key 및 SMTP/Telegram Bot Token은 `➕ 상세 인프라 설정 표시` 버튼을 클릭할 때만 창 크기가 `640x785`로 확장되며 노출되도록 인터페이스를 이원화했습니다.
  * **원클릭 일괄 설정 저장**: 개별 필드마다 달려있던 여러 개의 "저장" 버튼을 완전히 통합하여, 하단에 위치한 단 하나의 **`💾 모든 설정 및 자격 증명 저장`** 버튼을 통해 `uploader_config.json`에 영구히 저장될 수 있도록 입력 편의를 극대화했습니다.

### B. 웹 대시보드 지점 한글명 설정 구현 (Site Name Config)
* **배경**: 현장에 자동 장비 등록이 완료된 이후, 관리자가 대시보드 상단 헤더에 들어갈 지점명(예: 삼양사 인천공장)을 수동 코딩 없이 웹 화면에서 즉시 변경하고 DB에 저장할 수 있어야 합니다.
* **해결책**:
  * 대시보드 설정 모달(`⚙ 설정` - 패스코드 gated) 최상단에 **"🏢 지점 한글명 설정"** 입력 필드를 새롭게 추가했습니다.
  * 해당 값을 입력하고 설정을 저장하면, `site_config_v2` 테이블의 `site_name` 컬럼이 실시간으로 PATCH 갱신됩니다.
  * 페이지 로드 시 또는 타이틀 갱신 시 수정된 `site_name`이 화면 상단에 즉각 동적 동기화되어 표시됩니다.

### C. 기본값 삽입 및 배포 패키지 v5.1 리비전
* **결정 사항**: 배포 패키지인 `uploader_config.json` 내에 Supabase의 라이브 URL, API Key 및 기본 텔레그램 봇 토큰 정보를 기본값으로 탑재하여 파일 복사만으로 즉시 작동하도록 준비했습니다.
* **결과**: `계측기_PC_배포패키지_v5.0` 폴더를 원격 정리하고, v5.1 실행 파일 및 신규 배치 스크립트가 포함된 **`계측기_PC_배포패키지_v5.1`**로 안전하게 갱신했습니다.
