# 회의록: 현장 PC 업로더 UI 간소화 및 세부 주기/기동 제어 고도화

* **일시**: 2026년 7월 7일
* **참석자**: 사용자 (USER), AI 에이전트 (Antigravity)
* **주제**: 업로더 설정 간소화 및 기동 상태/동기화 주기 현장 설정 기능 추가

---

## 1. 요구사항 분석 및 변경 배경
1. **지점 식별자(Site ID) 입력란 제거**:
   * 현장 작업자가 설정 파일을 수동 편집하지 않고 UI에서 임의로 Site ID를 편집하여 DB 연동 관계를 오염시키는 문제를 사전에 차단하기 위해 화면에서 입력 폼을 제거하기로 결정했습니다.
   * 다만, 내부적으로는 `uploader_config.json`에 저장된 `site_id` 값을 계속 안전하게 참조하여 작동합니다.
2. **사이트 이름 레이블 명칭 단순화**:
   * 기존의 긴 기술적 설명 대신 직관적인 "사이트 이름 (Site Name)"으로 수정하여 인지 부하를 줄입니다.
3. **분 단위 동기화 주기 설정**:
   * 기본 900초(15분)로 고정된 상태였던 주기를 현장 네트워크 환경에 맞추어 분 단위로 자유롭게 지정(예: 10분, 15분 등)하고 저장 즉시 적용되도록 개선합니다.
4. **시작 시 자동 실행 및 일시정지 제어**:
   * 기기 가동 시 즉시 데이터를 업로드할지 또는 대기(일시정지) 모드로 켜질지를 GUI 체크박스를 통해 제어하고 설정에 보존합니다.

---

## 2. 세부 구현 및 변경 내역
* **`gui_uploader.py` 파일 리팩토링**:
  * **UI 레이아웃**:
    * `Site ID` 입력 필드를 삭제했습니다.
    * `사이트 이름` 입력란 라벨명을 "사이트 이름 (Site Name)"으로 수정했습니다.
    * `자동 동기화 주기 (분 단위)` Entry 위젯을 추가하여 `interval_seconds`와 60배수 연동되도록 구현했습니다.
    * `시작 시 자동 동기화 활성화` Checkbutton 위젯을 마운트하여 `is_paused` 설정을 Boolean 값으로 실시간 로드 및 토글 저장하도록 조치했습니다.
  * **자격 증명 일괄 저장 (`save_config`)**:
    * 저장 버튼 클릭 시 분 단위 값을 파싱하고 예외 처리(0 이하 또는 숫자가 아닌 값 에러 처리)를 거쳐 초 단위로 변환해 영구 반영합니다.
    * 체크박스의 활성화 상태(`start_active_var`)의 반대 값(`not start_active_var.get()`)을 `is_paused`에 주입해 기동 상태를 완벽히 바인딩했습니다.
  * **GUI 동적 새로고침 연동**:
    * `refresh_destination_label` 및 큐 리스너(`listen_queue`)에서 사이트 이름(`site_name`)을 상시 참조 및 리프레시하도록 리팩토링하여 원격 동기화 품질을 보강했습니다.
* **배포 패키지 바이너리 빌드 및 교체**:
  * `PyInstaller`를 사용해 크래시 및 GUI 오류가 해결된 완성형 단일 바이너리 `gui_uploader_v5.1.exe`를 재컴파일했습니다.
  * 현장 납품용 패키지 폴더(`계측기_PC_배포패키지_v5.1`) 내부의 실행 바이너리 및 config 템플릿 파일 구조를 새로운 명세에 맞춰 교체 반영했습니다.

---

## 3. 검증 결과
1. **Tkinter UI 정상 마운트**: 현장 프로그램 실행 시 사이트 이름, 장치명, 동기화 주기, 시작 시 실행 여부 체크박스가 깨짐 없이 2열 격자 구조로 안정적으로 배치됩니다.
2. **저장 기능 동작**: 10분을 입력하고 체크박스를 끈 채로 저장 시, `uploader_config.json`에 `"interval_seconds": 600`, `"is_paused": true` 형태로 정상 반영되며 기동 대기 타이머가 일시정지 상태를 바로 추종합니다.
3. **배포 패키지 동작**: `gui_uploader_v5.1.exe`를 복사하여 개별 가동할 때 정상 시작되며, 기존 Supabase 데이터 송수신 및 SMTP/텔레그램 이중 채널 테스트 알람 수신이 완벽하게 결합되어 운용됨을 최종 확인했습니다.
