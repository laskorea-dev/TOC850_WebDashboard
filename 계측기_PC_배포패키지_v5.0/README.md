# 💧 TOC B2B GUI Uploader v5.0 (Supabase V2) 배포 및 사용 안내서

본 프로그램은 계측기 PC의 데이터를 Supabase 클라우드 데이터베이스에 실시간 동기화하고, 알람 기준치를 초과할 시 경고 메일 및 텔레그램을 발송해 주는 Python GUI 프로그램의 신규 V2 아키텍처 버전(v5.0)입니다.

---

## 1. 주요 변경 사항 및 동작 원리

이전 버전(v4.3 이하)에서는 계측기 PC의 장비 ID(`Device_ID`)를 데이터 조회 기준으로 삼았기 때문에, PC가 고장 나서 새로운 PC로 교체할 경우 과거 데이터가 끊겨 보이는 문제가 있었습니다.

**v5.0 (V2 아키텍처)의 핵심 해결책**:
1. **지점 코드(Site_ID)**와 **물리 장치 ID(Device_ID)**의 완전 분리
   * `Device_ID`: 물리적인 PC의 Windows 호스트명(예: `TOC-PC-01`, `TOC-PC-02`)을 자동으로 획득하여 기록합니다.
   * `Site_ID`: 데이터가 귀속될 최종 고객 지점명(예: `Samyang_Incheon`)을 나타냅니다.
2. **데이터 연속성 보장**:
   * 대시보드 차트는 PC 이름이 아닌, 지점 코드인 `Site_ID`를 기준으로 쿼리합니다.
   * 이에 따라 PC가 교체되어 `Device_ID`가 바뀌더라도, 설정파일에 동일한 `Site_ID`만 적어주면 과거 PC와 현재 PC의 데이터가 하나의 차트 타임라인에 끊김 없이 연결되어 표시됩니다.
3. **Zero-Touch Onboarding (장비 자동 등록)**:
   * 미결정 장비나 테스트 장비의 경우 설정파일에 `"site_id": "auto"`로 두면, 컴퓨터 호스트명(예: `TOC-PC-01`)을 `Site_ID`로 사용하여 Supabase에 자동으로 등록 및 테스트가 가능합니다.

## 2. Supabase 데이터베이스 준비 (최초 1회 필수)

대시보드와 업로더 v5.0이 정상 가동하려면, Supabase 콘솔의 **SQL Editor**에 접속하셔서 아래 SQL DDL 스크립트를 붙여넣고 실행(Run)하셔야 합니다.

```sql
-- 1. 신규 지점 설정 테이블 생성
CREATE TABLE public.site_config_v2 (
    site_id text NOT NULL PRIMARY KEY,
    site_name text NOT NULL,
    passcode text NOT NULL DEFAULT '850',
    alert_emails text NULL,
    telegram_chat_ids text NULL,
    toc_alert_high jsonb NULL,
    use_single_table boolean NOT NULL DEFAULT true,
    created_at timestamp with time zone NOT NULL DEFAULT now()
);

-- 2. 신규 통합 계측 로그 테이블 생성
CREATE TABLE public.measure_logs_v2 (
    id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    "Date_Time" timestamp without time zone NOT NULL,
    "Site_ID" text NOT NULL,
    "Device_ID" text NOT NULL,
    "Channel" smallint NOT NULL,
    "Channel_Name" text NOT NULL,
    "TOC_Conc" numeric(10, 4) NOT NULL,
    "DilutionFactor" numeric(6, 2) NOT NULL DEFAULT 1.0,
    "MSIG" numeric(10, 4) NULL,
    "SLOP" numeric(10, 4) NULL,
    "ICPT" numeric(10, 4) NULL,
    "FACT" numeric(10, 4) NULL,
    "OFST" numeric(10, 4) NULL,
    "Add_note" text NULL,
    created_at timestamp with time zone NOT NULL DEFAULT now()
);

-- 인덱스 설정 (조회 속도 최적화)
CREATE INDEX idx_measure_logs_v2_site_id ON public.measure_logs_v2("Site_ID");
CREATE INDEX idx_measure_logs_v2_date_time ON public.measure_logs_v2("Date_Time");
```

## 3. 계측기 PC 프로그램 설정 방법 (`uploader_config.json`)

업로더 폴더 내의 `uploader_config.json` 파일을 열어 다음 두 값을 환경에 맞춰 편집합니다.

```json
{
    "supabase_table": "measure_logs_v2",
    "site_id": "Samyang_Incheon",
    "device_id": "auto",
    ...
}
```

* **`supabase_table`**: 반드시 `"measure_logs_v2"`로 고정해 줍니다.
* **`site_id`**:
  * **일반 현장**: 최종 설치되는 지점 식별 코드(예: `"Samyang_Incheon"`)를 입력합니다.
  * **사전 테스트**: 아직 출고할 곳이 정해지지 않았다면 `"auto"`로 둡니다. 이 경우 컴퓨터 이름(예: `TOC-PC-01`)이 `Site_ID`로 사용되어 자동 등록 및 조회가 가능해집니다.
* **`device_id`**: 항상 `"auto"`로 둡니다. 프로그램 실행 시 컴퓨터의 실제 Windows 이름을 자동으로 감지하여 데이터베이스의 `Device_ID` 컬럼에 남깁니다.

## 4. 프로그램 실행 방법

폴더 내에 위치한 **`1_업로더_실행하기.bat`**를 더블클릭합니다.
* 배치파일이 자동으로 v5.0 버전을 감지하여 백그라운드에서 `gui_uploader_v5.0.exe`를 즉시 실행합니다.
